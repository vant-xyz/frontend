Context

Adrena runs trading competitions as a core driver of platform engagement. In 2025, 50% of all trading volume came from competition activity. The current setup includes a P&L leaderboard, quests, streaks, and raffles. Adrena wants to build better, more engaging trading competitions than any other perp DEX on Solana.

What We're Looking For

Design and build a new competition module or meaningful improvement to Adrena's existing trading competition infrastructure. The goal is to make competitions more engaging, more rewarding, and more fun than what exists on any competing perp DEX.

Deliverables

Competition Design Document

    Proposed competition format (can be a new type or an improvement to existing)

    Rules, scoring mechanics, and reward structure

    How it integrates with Adrena's existing infrastructure (leaderboard, quests, streaks, raffles)

    Why this is more engaging than current alternatives on other perp DEXs

    Edge cases and abuse prevention

Working Prototype or Implementation

    Functional code that can be reviewed and tested

    Integration with Adrena's existing systems (coordinate with the Adrena team for access)

    Documentation on how to deploy and configure

Testing & Feedback

    Run a test competition with a small group

    Collect feedback and document results

    Recommendations for iteration

Requirements

    Experience with Solana development

    Understanding of perps/DeFi trading mechanics

    Coordinate with the Adrena team on integration requirements (intro will be provided)

    Code must be clean, documented, and deployable
